# C00KUP · pacote de design

Este pacote tem o visual final do plugin (direção D), o nome novo e o prompt para o Claude Code aplicar tudo.

## O que há aqui

| Pasta / ficheiro | Para quê |
|---|---|
| `design/` | A interface em imagem (parado e a gravar) e em HTML |
| `SPEC.md` | Cores, fontes, medidas, estados e identificadores |
| `PROMPT-claude-code.md` | O texto que colas no Claude Code |
| `fonts/` | Fontes Schibsted Grotesk e Martian Mono (licença OFL, grátis) |
| `assets/` | Símbolo 808College e wordmark C00KUP em SVG |

Canvas com as 4 direções: https://claude.ai/artifact/DmVLmjWU85wSUAYHzLqNPB

## Passo a passo

1. **Descompacta o zip.** Dá dois cliques nele e aparece a pasta `design-c00kup`.
2. **Envia a pasta para o GitHub.**
   - Abre o repositório: https://github.com/fdefrederico-maker/808-reels-capture
   - Carrega em **Add file → Upload files**.
   - Arrasta a pasta `design-c00kup` inteira para a página.
   - Em baixo, carrega no botão verde **Commit changes**.
3. **Abre uma sessão nova do Claude Code** ligada a esse repositório.
4. **Cola o prompt** que está em `PROMPT-claude-code.md` (tudo o que vem depois da linha `---`).
5. **Quando a Release nova sair**, segue as instruções de instalação que o Claude Code te der.
